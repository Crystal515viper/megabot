# PAPER TRADING MODE - Руководство по использованию

## Обзор
Система поддерживает режим Paper Trading для безопасного тестирования стратегии без реальных денег.

## Конфигурация

### 1. Переменные окружения (.env)
```bash
# Глобальный флаг режима
PAPER_TRADING=True

# Фейковый баланс для тестов (USDT)
PAPER_BALANCE_INITIAL=10000

# Задержки симуляции (мс)
PAPER_ORDER_FILL_DELAY_MS=500
PAPER_API_LATENCY_MS=100
```

### 2. Конфигурация ботов (config/bot_*.yaml)
```yaml
trading:
  paper_mode: true  # Включить режим симуляции
  
  # Параметры симуляции
  simulation:
    fill_probability: 0.95  # Вероятность исполнения ордера
    slippage_max_pct: 0.1   # Максимальное проскальзывание %
    partial_fill_chance: 0.1 # Вероятность частичного исполнения
```

## Как это работает

### Симуляция исполнения ордеров
- Лимитные ордера исполняются с вероятностью 95%
- Рыночные ордера исполняются мгновенно с небольшим проскальзыванием
- Частичное исполнение моделируется случайно (10% шанс)

### Фейковый баланс
- Начальный баланс берется из `PAPER_BALANCE_INITIAL`
- Все PnL расчеты ведутся на виртуальном счете
- Реальные API-ключи биржи не требуются

### Задержки
- Эмуляция сетевой задержки API
- Имитация времени подтверждения ордера
- Настройка через `PAPER_*_DELAY_MS`

## Отличия от Production режима

| Параметр | Paper Trading | Production |
|----------|---------------|------------|
| API Keys | Не требуются | Обязательны |
| Реальные деньги | Нет | Да |
| Задержки | Эмулируются | Реальные |
| Риск потерь | Нулевой | Есть |

## Запуск в режиме Paper Trading

```bash
# 1. Установите флаг в .env
echo "PAPER_TRADING=True" >> .env

# 2. Запустите систему
docker compose up -d

# 3. Проверьте логи ботов
docker compose logs bot_long | grep "PAPER MODE"
# Ожидаемый вывод: [INFO] PAPER MODE: Simulating order execution
```

## Мониторинг

В режиме Paper Trading метрики помечаются префиксом `paper_`:
- `paper_orders_total` - количество симулированных ордеров
- `paper_pnl_total` - виртуальный PnL
- `paper_balance` - текущий баланс

## Переход в Production

⚠️ **ВАЖНО**: Перед переключением убедитесь:

1. Измените `PAPER_TRADING=False` в `.env`
2. Добавьте реальные API-ключи биржи
3. Установите минимальные размеры позиций
4. Протестируйте на малых суммах
5. Включите все проверки безопасности

```bash
# Production конфигурация
PAPER_TRADING=False
EXCHANGE_API_KEY=your_real_key
EXCHANGE_API_SECRET=your_real_secret
```

## Тестирование стратегии

Рекомендуемый процесс:

1. **Backtest** - исторические данные
2. **Paper Trading** - реальное время, фейковые деньги (2-4 недели)
3. **Small Live** - реальные деньги, минимальные позиции
4. **Full Production** - полноценная торговля

## Логирование

Все действия в Paper режиме логируются с префиксом `[PAPER]`:
```
[PAPER] Order BTCUSDT BUY 0.1 @ 45000 - SIMULATED FILL
[PAPER] Position #123 PnL: +$150.50 (unrealized)
[PAPER] Trailing stop activated at $45500
```
