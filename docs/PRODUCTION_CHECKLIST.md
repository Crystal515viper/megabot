# Чеклист запуска MegaBot в Production

## Предварительные требования

- [ ] Docker и Docker Compose установлены
- [ ] Python 3.11+ доступен локально
- [ ] GitHub Secrets настроены (для CI/CD)
- [ ] Доменное имя для API (опционально)
- [ ] SSL сертификаты (рекомендуется Let's Encrypt)

## 1. Конфигурация окружения

- [ ] Скопировать `.env.example` в `.env`
- [ ] Установить `PAPER_TRADING=False`
- [ ] Сгенерировать надежный `SECRET_KEY`
- [ ] Добавить реальные credentials PostgreSQL
- [ ] Добавить реальные credentials Redis
- [ ] Вставить API-ключи биржи (Binance/Bybit)
- [ ] Добавить Telegram Bot Token и Chat IDs
- [ ] Проверить все пароли на сложность

## 2. Безопасность

- [ ] API-ключи биржи имеют IP-whitelist
- [ ] API-ключи имеют минимальные права (только торговля, без вывода)
- [ ] PostgreSQL доступен только внутри Docker сети
- [ ] Redis требует пароль (установлен в `.env`)
- [ ] Порты 5432, 6379 не открыты наружу
- [ ] Файл `.env` добавлен в `.gitignore`
- [ ] Настроен Firewall (UFW/iptables)

## 3. База данных

- [ ] PostgreSQL запущен и доступен
- [ ] Миграции выполнены: `docker compose run orchestrator alembic upgrade head`
- [ ] Создан backup-скрипт для БД
- [ ] Настроено автоматическое резервное копирование

## 4. Тестирование

- [ ] Все юнит-тесты проходят: `pytest tests/ -v`
- [ ] Coverage > 80%
- [ ] Integration тесты с mock-биржей пройдены
- [ ] Paper Trading протестирован (минимум 48 часов)
- [ ] Проверена работа всех ботов в режиме симуляции
- [ ] Telegram уведомления работают

## 5. Мониторинг и логирование

- [ ] Prometheus собирает метрики со всех сервисов
- [ ] Grafana дашборд импортирован и настроен
- [ ] Настроены алерты (опционально Alertmanager)
- [ ] Логи сохраняются с ротацией (logrotate/docker driver)
- [ ] Центральный сбор логов (ELK/Loki) настроен (опционально)

## 6. Производительность

- [ ] Выделено достаточно RAM (минимум 4GB для всей системы)
- [ ] Выделено достаточно CPU (минимум 2 cores)
- [ ] SSD диск для PostgreSQL volume
- [ ] Настроены лимиты ресурсов в Docker Compose

## 7. Деплой

- [ ] Запущен скрипт деплоя: `./scripts/deploy.sh`
- [ ] Все контейнеры в статусе `healthy`
- [ ] Healthcheck эндпоинты отвечают
- [ ] API Gateway доступен извне
- [ ] WebSocket соединения стабильны

## 8. Post-deployment проверка

- [ ] `/api/v1/health` возвращает 200 OK
- [ ] `/api/v1/status` показывает корректные данные
- [ ] Боты отправляют heartbeat в Redis
- [ ] Orchestrator принимает сигналы
- [ ] Telegram бот отвечает на `/start` и `/status`
- [ ] Grafana отображает метрики в реальном времени

## 9. План действий при авариях

- [ ] documented процедура остановки: `docker compose down`
- [ ] documented процедура восстановления из backup
- [ ] Контакты ответственных записаны
- [ ] Каналы экстренной связи определены

## 10. Финальные шаги

- [ ] Включен режим реальных денег (`PAPER_TRADING=False`)
- [ ] Первая позиция открыта с минимальным размером
- [ ] Проверено закрытие позиции и расчет PnL
- [ ] Команда проинформирована о запуске

---

## Экстренная остановка

```bash
# Немедленная остановка всех ботов
docker compose stop bot_long bot_short

# Полная остановка системы
docker compose down

# Проверка что ордера закрыты (через API биржи вручную)
```
